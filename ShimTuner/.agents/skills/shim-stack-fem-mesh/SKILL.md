# 阀片堆叠有限元网格化 (Shim Stack FEM Meshing by Radius Steps)

为 ShimTuner 物理内核服务的**网格化技能**: 给定一组环形阀片(锥形阀片堆叠),
自动构造"每一个半径台阶都落在节点/单元边界上"的有限元网格, 并提供可直接运行
的 numpy 模板, 避免从 0 手写网格化算法。

## 何时使用 / 触发场景

- 需要生成、修改或解释堆叠阀片的 FEM 网格(单元表/节点表)。
- 需要把理论 md 的"在径向阀片台阶处切分 + 圆周按角度切分"实现为代码。
- 需要按覆盖层数 `k(r)` 给单元赋值刚度 `D_e = Σ Dᵢ`。
- 扩展新载荷/新几何(例如非轴对称、带节流孔的活塞面)时的网格改造。
- **不要**在只需轴对称小挠度解时重写组装求解: 直接复用 `shim_physics_core.py`
  的 `ShimStackCore`(网格+组装+解析对照已全部就绪)。

## 核心规则(网格化的"宪法", 所有实现必须遵守)

1. **半径台阶必须是节点**: 每片阀片的内半径 `a`、外半径 `b`(以及夹持半径
   `clamp`)都是"关键半径"。关键半径集合
   `R_c = sorted({clamp} ∪ {a_i} ∪ {b_i})`(去重)。关键半径处必须有节点/单元边界,
   否则单元会横跨刚度阶梯导致 `D_e` 错误。
2. **带内属性恒定**: 两个相邻关键半径之间覆盖片数 `k` 恒定; 单元刚度
   `D_e = Σ Dᵢ`(只数单元中点被覆盖的阀片)。`Dᵢ = E·tᵢ³ / (12(1−ν²))`。
3. **细分策略**: 每段关键半径环带按目标单元尺寸 `h_target` 均匀细分
   (`每带单元数 = max(1, ceil(带宽 / h_target))`), 带与带之间不共享中间节点之外的
   约束, 端点在相邻带之间去重共享。注意: ratio 恰为整数时可能被浮点噪声扰动,
   模板用相对容差 1e-9 的最近整数取整——见 `_count_elems`)。
4. **单位约定**: 几何输入一律 mm; 计算内部一律 SI(m, Pa); `半径 = 直径/2 · 1e-3`。
5. **层顺序**: `layers` 自上而下(第 0 片直接受阻尼油均布压强), 其他片只经层间
   接触传力(与 `shim_physics_core.py` 一致)。
6. **边界**: 内缘 clamp 处固支(`w=0, θ=0`); 外缘自由(自然边界条件)。
   适用前提: 小挠度 `h ≪ t`(md 第 6 节), 超出后仅作趋势参考。

## 标准流程

1. **读理论**: 先看 `../../../ShimTunerPhysics.md`(单片解析解、等径/锥形堆叠
   假设)与现有实现 `../../../shim_physics_core.py`(1D 环元基准代码)。
2. **判断维度**:
   - 载荷与几何均轴对称 → **1D 轴对称环元网格**。优先直接调用 `ShimStackCore`;
     若需自建网格, 按 `references/radial-mesh-1d.md` + `scripts/build_mesh_1d.py`。
   - 存在非轴对称载荷/几何(如偏心孔、周向变化的油压) → **2D 极坐标网格**
     (径向关键半径分段 × 周向等角扇形梯形单元),
     按 `references/polar-mesh-2d.md` + `scripts/build_mesh_2d.py`。
3. **数据校验**: 每片 `d_out > d_in > 0`、`t > 0`; `clamp ≥ min(aᵢ)`(否则出现
   无支撑环); `clamp < min(bᵢ)`(否则某片完全悬空, 应报错)。
4. **生成网格**(直接复制模板函数或调用), 断言关键半径全部出现在节点坐标中。
5. **赋属性**: 单元覆盖数 `k`、`D_e`; 顶片受压面(第 0 片环形面)标记。
6. **组装/求解/边界**后必须跑**验证清单**(见下), 全部通过才算完成。

## 验证清单(交付前逐条自检)

| # | 检查 | 判据 |
|---|------|------|
| 1 | 关键半径都是节点 | 每个 `aᵢ/bᵢ/clamp` 与某节点坐标差 `< 1e-12 m` |
| 2 | 单元属性非零且按带恒定 | 同一带内 `D_e` 一致; 所有单元 `k ≥ 1` |
| 3 | 单片对照 md 解析解 | 单阀片网格外缘挠度 vs `Φ(a/b,ν)·p·b⁴/D`, 相对误差 `< 1e-3` |
| 4 | 等径堆叠退化 | k 片等径同厚堆叠的挠度 = 单片挠度/k |
| 5 | 收敛性 | 加密网格(如 400→1200 单元)结果相对变化 `< 1e-4` |
| 6 | 2D 几何守恒 | 全部单元面积和 = `π·(b_max² − r_min²)`(域内缘=最小关键半径, 通常即 clamp) |
| 7 | 2D 轴对称载荷还原 | 同一算例 2D 与 1D 外缘挠度一致(周向均匀) |
| 8 | 大挠度警告 | 若 `max(h/t) > 0.2`, 输出 md 适用范围警告 |

数值回归: `python shim_physics_core.py`(自带 FEM vs 解析对照表)必须不报错。

## 常见坑(写代码时对照)

- 忘了把某个 `bᵢ`(锥形堆叠最短片的台阶)放进节点表 → 该台阶被抹平, 刚度偏大。
- 用浮点 `==` 比较半径; 统一用容差(节点坐标是 m 量级, 用 `1e-12` 以上容差去重)。
- 2D 周向连通性忘了 `(j + 1) % nθ` 回绕 → 网格在 θ=2π 处开缝。
- 2D 角度用了角度制而 numpy 三角函数/`dθ` 用弧度制混算。
- 只数"单元中心被覆盖"的片; 不要数带外片, 也不要用整片外径覆盖全带。
- 载荷只加在顶片环形面 `[a₀, b₀]` 上(1D 载荷向量公式见 radial-mesh-1d.md)。
- 2D 单元长宽比失控: 外缘弧长 ≈ `r·dθ` 与径向尺寸应同量级, 自检打印提示。
