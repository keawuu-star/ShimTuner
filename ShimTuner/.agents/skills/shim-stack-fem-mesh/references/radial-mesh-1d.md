# 1D 轴对称环元径向网格规范 (Radius-Step Radial Mesh)

> 依据 `ShimTunerPhysics.md`「等径/锥形阀片堆叠」; 基准实现:
> `shim_physics_core.py` 的 `ShimStackCore`。本文件描述**网格生成**的精确规范,
> 供移植/改造/教学使用。

## 0. 适用范围

- 载荷与几何**轴对称**(顶片整环受均布压强, 或环向均布的环线载荷)。
- 小挠度线性 Kirchhoff 板弯曲(`h ≪ t`, md 第 6 节)。
- 层间全程接触不分离、无摩擦滑移 → 堆叠等效为径向**阶梯变刚度**板,
  `D(r) = Σ 覆盖该半径的片的 Dᵢ`。

## 1. 输入与单位

```
layers        自上而下排列的阀片列表; layers[0] 直接受油压。
              每片: (d_in_mm, d_out_mm, t_mm)
clamp_radius_mm  夹持(压紧螺栓)半径。默认 = min(d_in_mm)/2  (全部内孔半径最小值)
n_elem_base    目标径向单元总数(近似); 实际每带取整
E, nu          材料: Sandvik 7C27Mo2 默认 E=200e9 Pa, ν=0.30
内部半径(米): r = d_mm / 2 * 1e-3
```

## 2. 网格算法(精确步骤)

```
输入: layers, clamp_m, n_elem_base
1. 关键半径集合(去重, 容差 ~1e-12 m):
       R_c = sort( {clamp_m} ∪ {aᵢ} ∪ {bᵢ} )
2. 目标最大单元长度:   h_max = (R_c[-1] − clamp_m) / n_elem_base
3. 逐段生成节点: 对每段 [r₀, r₁] ∈ R_c:
       n_elem = max(1, ceil((r₁ − r₀) / h_max))     # 该段内单元数
       (ratio 恰为整数时浮点噪声可能把 100 算成 100.000…01 → 101;
        模板 `_count_elems` 用 1e-9 相对容差就近取整, 保证 h 落在
        目标尺寸的整数倍时每带单元数稳定)
       段内节点 = linspace(r₀, r₁, n_elem + 1); 端点与邻段共享(只保留第一个内点以后)
4. 全网格节点 r_nodes[0..N-1] (严格递增), 单元长度 le[e] = r_nodes[e+1] − r_nodes[e]
5. 每个单元(取中点 r_mid)统计覆盖片数 k 与刚度:
       coverᵢ(e) = 1  若 r_mid ∈ [aᵢ − tol, bᵢ + tol] 且该片延伸到 clamp 之外
       k(e)     = Σᵢ coverᵢ(e)         # 必须 ≥ 1, 否则报"无覆盖单元"
       D_e(e)   = Σᵢ Dᵢ,  Dᵢ = E·tᵢ³ / (12(1−ν²))
6. 校验: 每个关键半径都必须出现在 r_nodes 中 (误差 < 1e-12 m)。
```

工作模板见 `scripts/build_mesh_1d.py`(输出 r_nodes / le / coverage / D_e /
逐段表格, 自带几何断言)。

## 3. 环元公式(若需要自写组装; 与基准实现逐项一致)

每个径向单元 2 节点 × (w, θ=dw/dr) 共 4 DOF。局部坐标 `x = (r−r₀)/le`,
立方 Hermite 形函数(物理斜率):

```
N = [1−3x²+2x³,  le(x³−2x²+x),  3x²−2x³,  le(x³−x²)]
dN/dr = dN/dx / le,   d²N/dr² = d²N/dx² / le²
```

单元刚度(能量 `U = π ∫ D [ r(w″)² + 2ν w″w′ + (w′)²/r ] dr` 导出的弱形式):

```
K_e = 2π ∫_{r₀}^{r₁} D_e · [ r·(N″ᵀN″) + ν·(N″ᵀN′ + N′ᵀN″) + (1/r)·(N′ᵀN′) ] dr
```

单元载荷(顶片环形受压面 `[a₀,b₀]` 与单元的交集上均布压强 p):

```
f_e = 2π p ∫ Nᵀ · r dr          (对全周积分; 用 5 点 Gauss-Legendre 足够)
```

环线载荷(如模拟某个台阶处的集中传力): 总力 F 作用在半径 c 的圆上 →
`f_e += F · N(c)`, `c` 须落在关键半径上才有节点意义。

固支边界: 删除 clamp 节点两行两列(`w`、`θ` 对应的 DOF); 外缘自由为自然边界,
无需处理。系统线性 → 解一次单位压强, 任意 p 线性放大;
外缘开度 `h(e) = w_unit[外缘节点] · p`。

## 4. 算例(md 示例: Ø10/Ø9/Ø8 锥形堆叠, 内径 6, 全厚 0.1, clamp 3.0 mm)

关键半径(mm): `{3.0, 4.0, 4.5, 5.0}`。

| 环带 r (mm) | 宽度 (mm) | 覆盖片数 k | D_e / D₁ | n_elem_base=400 时单元数 |
|---|---|---|---|---|
| 3.0 → 4.0 | 1.00 | 3 (全 3 片) | 3 | 200 |
| 4.0 → 4.5 | 0.50 | 2 (Ø10+Ø9) | 2 | 100 |
| 4.5 → 5.0 | 0.50 | 1 (仅 Ø10) | 1 | 100 |

- 单元总数 = 200 + 100 + 100 = 400。
- 顶片受压面 `[a₀,b₀] = [3, 5] mm`(载荷只在第 0 片的环形面上, 即整个网格域)。
- 参照: 单片 Ø10 解析外缘挠度 `h₁ = Φ·p·b⁴/D₁`; 该锥形堆叠解必须介于
  "3 片等径(≈h₁/3)"与单片之间, 且由 8 片外缘 `r=4.0mm`、9 片外缘 `r=4.5mm`
  处的中间节点刚度自然过渡(与 md 描述的力传递路径一致)。

## 5. 验证方法

1. 单片对照: 任意 (d_in,d_out,t), FEM vs `Φ(ρ,ν)·p·b⁴/D`, 相对误差 < 1e-3。
2. 等径退化: `[ShimLayer(6,10,0.1)] * k` 的外缘挠度 = 单片/k。
3. 收敛性: n_elem_base ∈ {100, 400, 1200} 结果相对变化 < 1e-4。
4. 基准回归: `python shim_physics_core.py` 不报错, 打印对照表。

## 6. 与现有代码的关系 / 移植要点

- `shim_physics_core.py::ShimStackCore` 已实现本规范的网格 + 组装 + 求解 +
  自检; **轴对称任务默认直接调用它**, 传 `layers=[ShimLayer(...)]` 与
  `n_elem_base`、`clamp_radius_mm` 即可。
- 需要网格数据本身(例如换单元类型、写日志、可视化)时, 可改用本技能模板
  `scripts/build_mesh_1d.py` 的输出 dict。
- 迁移到非线性大挠度: 网格不变, 只换控制方程与迭代; 节点须仍钉在台阶上。
