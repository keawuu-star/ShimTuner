# 2D 极坐标梯形(扇形)网格规范 (Polar r-θ Trapezoid Mesh)

> 对应理论文档的网格化描述: "按半径差值将阀片在径向切分, 并按角度将阀片均匀
> 切分得到**梯形元素**; 在径向阀片台阶处切分阀片, 在圆周上按角度切分。"

## 0. 何时用 2D, 何时不要用

**不要**因为"更精细"就用 2D: 轴对称载荷下 1D 环元(见 radial-mesh-1d.md)是
精确且便宜得多的选择(节点数差 ~nθ 倍)。2D 网格只用于:

- 载荷沿周向变化(如活塞面上节流孔/偏置油压、径向力);
- 几何沿周向变化(开口环、缺口、去重孔);
- 需要输出 2D 应力/挠度场云图。

对称性优化: 若载荷关于某条直径对称 → 只建 180°(半环)扇区, 对称面加相应边界
条件; 若按节流孔周期分布 → 建单周期扇区。可节省 nθ/扇区数 倍内存。

## 1. 网格拓扑

```
径向: 与 1D 完全相同的"关键半径"规则
    R_c = sort({clamp} ∪ {aᵢ} ∪ {bᵢ});  每带细分 n_elem = max(1, ceil(带宽/h_max))
    (整数边界用 1e-9 相对容差就近取整, 见 scripts/build_mesh_1d.py `_count_elems`)
    径向节点 r[0..n_r−1], 径向单元(环带小段)索引 e_r = 0..n_cell_r−1
周向: 全环均匀切分
    nθ 段(nθ 建议取偶数, 便于扇形对称应用), dθ = 2π/nθ
    节点 θ[j] = j·dθ (j = 0..nθ−1), 第 nθ 个与第 0 个重合 → 连通性回绕
```

**节点编号(r 优先)**: 径向索引 i、周向索引 j →
`global = i·nθ + j`, 总节点 `N = n_r·nθ`。

**单元连通性**(梯形/曲边四边形, 逆时针):

```
对每个径向单元 e_r = (i → i+1) 与每个扇区 j:
    n00 = i·nθ + j
    n01 = i·nθ + (j+1)%nθ
    n11 = (i+1)·nθ + (j+1)%nθ
    n10 = (i+1)·nθ + j
    conn = [n00, n01, n11, n10]
```

总单元数 `M = n_cell_r · nθ`(回绕使环闭合, 无重复接缝节点)。

## 2. 每单元几何量(精确闭式, 不用数值积分算面积)

径向单元跨 `[r₁, r₂]`、扇区跨 `[θ₁, θ₂]`, `Δθ = θ₂−θ₁`:

| 量 | 公式 |
|---|---|
| 面积 A | `A = (Δθ/2)·(r₂² − r₁²)` |
| 形心半径 r̄ | `r̄ = (2/3)·(r₂³ − r₁³)/(r₂² − r₁²)` |
| 形心角度 θ̄ | `θ̄ = (θ₁+θ₂)/2` |
| 内/外弧长 | `s₁ = r₁·Δθ`, `s₂ = r₂·Δθ` |
| 径向宽度 | `Δr = r₂ − r₁` |
| 长宽比提示 | 外缘 `s₂ / Δr`(自检打印, 远离 1 太多需调 nθ 或径向细分) |

几何守恒校验: `Σ A = π·(r_max² − r_min²)`, 其中域内缘 `r_min` = 最小关键半径
(默认即 clamp 圆; 若 clamp 半径大于某片内孔半径, 网格仍从内孔最小半径起建,
与 1D/基准实现语义一致, clamp 圆在内部作为固支圈)。

## 3. 单元属性赋值

- 单元径向中点半区间内统计覆盖: 与 1D 完全一致 → 覆盖数 `k`、`D_e = Σ Dᵢ`。
- 受压面标记: `face = 1` 当单元中点落在顶片环形面 `[a₀, b₀]`(供载荷装配)。
- 提示: 若把堆叠当作多层板且要考虑中性面偏移/层间滑移, 那是**物理模型扩展**,
  不要在网格层偷偷"等效厚度"——网格只负责给每单元一个 `D_e` 与几何;
  材料属性如何进单元矩阵由单元公式决定(基准模型见理论文档: 仅弯曲刚度相加)。

## 4. 边界条件

- 内缘 clamp 圆: `i=0` 整圈节点固支(板 DOF 全约束); 若用 Mindlin 单元则
  `w = θr = θt = 0`。
- 外缘自由: 自然边界条件。
- 接缝 θ=0/2π: 连通性已回绕, 无需重复节点; 若求解器要求"无卷绕"网格,
  也可复制第 0 圈为第 nθ 圈(节点数 n_r·(nθ+1)), 两种编号在文档里写明即可。
- 扇区对称面(如只用半环): 在 θ=const 边界的节点上约束周向斜率/转动分量,
  并取消该边的回绕元素。

## 5. 单元公式选择建议(网格与求解器解耦)

网格模板只产几何与属性; 板单元任选其一, 但注意:

- Kirchhoff(C1)四节点弯曲元在非规则四边形上实现复杂 → 不推荐。
- **推荐**: 4 节点 Mindlin 板(每节点 w, θr, θt), 采用减缩积分或 MITC4
  修正以抗剪切锁死; 在物理极坐标 `(r, θ)` 或直角 `(x = r·cosθ, y = r·sinθ)`
  下做等参变换(建议直角坐标 + 标准等参四边形, 几何精度足够)。
- 简单备选: 每个梯形沿短对角线剖成两个 3 节点 Mindlin 三角, 避免四边形畸变
  讨论, 代码最简单。
- 2D 验证: 轴对称载荷下 2D 解应还原 1D 环元/解析解(周向均匀, 误差 < 1e-3),
  再叠加非轴对称载荷才有意义。

## 6. 算例(Ø10/Ø9/Ø8, 内径 6, t=0.1, clamp 3.0 mm)

径向同 1D: 环带 [3,4]/[4,4.5]/[4.5,5] mm, 覆盖 3/2/1, 单元 200/100/100
(n_elem_base=400)。

取 `nθ = 120`(建议取 2~4 的倍数):

| 量 | 数值 |
|---|---|
| 径向节点 n_r | 401 |
| 单元总数 M | 400 × 120 = 48 000 |
| 节点总数 N | 401 × 120 = 48 120 |
| 每带单元 | 24 000 / 12 000 / 12 000 |
| 外缘周向弧长(带3) | `2π·5mm/120 ≈ 0.262 mm` |
| 径向单元长(带3) | `0.5mm/100 = 0.005 mm` → 长宽比 ≈ 52 ⚠ 太细 |

**长宽比纠正示例**: 2D 场景应放宽径向细分(例如带内单元长 ≈ 0.1 mm →
带3 每带 5 单元… 或 nθ=48, 弧长 0.65 mm 配径向 0.1~0.2 mm), 并以"2D vs 1D
还原误差"与收敛性试验定最终密度。模板自检会打印长宽比, 务必检查后再装配。

## 7. 常见坑

1. 忘记 `% nθ` 回绕 → 接缝处缺一圈单元(几何守恒校验会抓住)。
2. 角度制/弧度制混用 → `dθ` 与 `np.cos/sin` 的输入不一致, 元素面积错乱。
3. 径向节点在台阶处没强制 → `D_e` 在某单元内"平均"了两种覆盖, 静力平衡失真。
4. nθ 与径向密度失衡 → 长宽比 >10 的单元降低精度/引发锁死, 模板自检已提示。
5. 全环网格 + 只有一条对称载荷 → 白花 ~2× 内存; 先判断对称性再切扇区。
